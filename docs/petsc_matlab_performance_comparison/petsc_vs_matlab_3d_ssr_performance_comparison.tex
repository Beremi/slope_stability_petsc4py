\section{Methodology}
The study definition uses indirect SSR only and P2 elements only. It covers homogeneous 3D SSR, heterogeneous 3D SSR, and the benchmarked heterogeneous 3D seepage SSR COMSOL-transition case.

PETSc runs use \code{mpirun -n 8} with \code{OMP\_NUM\_THREADS=1}. MATLAB runs use \code{OMP\_NUM\_THREADS=8} and the BoomerAMG MATLAB path with 8 threads. The dry PETSc and MATLAB runs for a given case share the same continuation horizon, estimated by a PETSc smoke run on the coarsest physical mesh with \code{d\_lambda\_diff\_scaled\_min = 0.01}. Main runs then disable the continuation delta-lambda stop and terminate on \(\omega_{\max}\). The seepage section uses the existing benchmark-suite COMSOL-transition SSR artifacts with \code{lambda\_init = 1.0}, \code{d\_lambda\_init = 0.1}, and \code{d\_lambda\_diff\_scaled\_min = 0.005}.

The heterogeneous 3D case adds one appendix variant where PETSc Newton stopping changes from relative residual to absolute delta-lambda with tolerance \(10^{-4}\).

The homogeneous and heterogeneous dry cases use the requested relative-residual Newton tolerance \(10^{-4}\). The normalized seepage inputs use the benchmarked COMSOL-transition PETSc/MATLAB pair and exclude the waterlevels/concave study rows until that separate seepage parity issue is resolved.
