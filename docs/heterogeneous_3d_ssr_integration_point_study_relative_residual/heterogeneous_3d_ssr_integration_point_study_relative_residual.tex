\section{Goal}
This note studies how tetrahedral integration-point count changes the continuation response of the standard heterogeneous 3D SSR benchmark on \texttt{SSR\_hetero\_ada\_L1}. This residual-stop variant repeats the same \texttt{P1}, \texttt{P2}, and \texttt{P4} element comparison as the delta-\(\lambda\) study, but switches the continuation Newton stop back to the old default \texttt{relative\_residual = 1e-4}. The comparison focuses on continuation-curve shape, runtime, final load level at a shared horizon, and numerical stability.

\section{Benchmark Setup}
The shared comparison target is $\omega_{\mathrm{final}} = \num{\StudyOmegaFinal}$. Every run uses the same continuation settings as the companion delta-\(\lambda\) report except for the continuation Newton stop: \texttt{secant} indirect continuation, \texttt{step\_max = 100}, \texttt{d\_lambda\_diff\_scaled\_min = 1e-4}, and Newton \texttt{relative\_residual = 1e-4}. The initial Newton solve also uses \texttt{relative\_residual = 1e-4}. The execution environment is fixed at \texttt{mpirun -n \StudyMpiRanks} with \texttt{OMP\_NUM\_THREADS = 1}, \texttt{node\_ordering = block\_metis}, \texttt{constitutive\_mode = overlap}, and the PETSc-side \texttt{PETSC\_MATLAB\_DFGMRES\_HYPRE\_NULLSPACE} linear solver.

The published matrix is element-specific: \texttt{P1} uses \texttt{q1}, \texttt{q4}, \texttt{q11}, \texttt{q24}, and \texttt{q45}; \texttt{P2} uses \texttt{q4}, \texttt{q11}, \texttt{q24}, and \texttt{q45}; and \texttt{P4} is reported only for \texttt{q24} and \texttt{q45}. This keeps the \texttt{q11} rule as the established \texttt{P2} baseline in the code base while dropping the unhelpful \texttt{P4/q11} failure from the published comparison. The \texttt{q45} curve is treated as the within-element reference because it is the richest rule in the published comparison matrix.

One methodological clarification matters here: the standard \texttt{SSR\_hetero\_ada\_L1} benchmark reaches the familiar $\omega \approx 6.7\times 10^6$ scale only on the indirect continuation path. The earlier direct-study omega scale was therefore not the same problem, so this corrected study uses the standard indirect heterogeneous 3D SSR capture path throughout.
The wall-clock policy is also element-specific: \texttt{P1} and \texttt{P2} retain a \SI{1200}{s} guard, while \texttt{P4} is allowed to run without a wall-clock timeout so the higher-order curves can finish unless a real watchdog abort is triggered by solver pathologies such as repeated zero-correction stalls.

\section{Reference-Element Quadrature Rules}
The tetrahedral rules used in this study are defined on the unit reference tetrahedron with vertices $(0,0,0)$, $(1,0,0)$, $(0,1,0)$, and $(0,0,1)$. Table~\ref{tab:reference-quadrature-summary} summarizes the five published rules. The point coordinates and weights are taken directly from the implementation in \texttt{src/slope\_stability/fem/quadrature.py}, and the point clouds are visualized in Figure~\ref{fig:reference-tetra-quadratures}. Marker size is proportional to $|w|$ and red markers indicate negative quadrature weights.

All five rules integrate over the same reference volume, so the weights sum to $1/6$ in every case. The low-order \texttt{q1} and \texttt{q4} rules use only positive weights; \texttt{q11} introduces one negative-weight point and is the established \texttt{P2} baseline in this repository; \texttt{q24} is the first fully positive high-order rule in the published set; and \texttt{q45} again contains one negative-weight point while supplying the richest spatial sampling used in the comparison.

\section{Reading The Tables}
The table reports the wall time for each run, accepted continuation steps, the terminal $\omega$ reached, the interpolated $\lambda(\omega_{\mathrm{final}})$ when that interpolation is valid, and the shift in $\lambda(\omega_{\mathrm{final}})$ relative to the \texttt{q45} curve inside the same element family. This makes it possible to separate three effects:

\begin{itemize}
\item continuation-curve agreement inside one element family,
\item cost growth as integration-point count increases,
\item and outright instability or inability to reach the shared horizon.
\end{itemize}
